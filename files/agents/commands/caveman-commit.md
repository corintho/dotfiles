Load and activate the caveman-commit skill.

Use this command to generate a concise, well-formatted commit message following Conventional Commits format:
- Subject line ≤50 characters
- Use commit type: feat, fix, chore, refactor, docs, style, test
- Include scope when relevant
- Use body only when "why" isn't obvious from diff
- Keep body sections brief and factual

The skill automatically activates when staging changes.
