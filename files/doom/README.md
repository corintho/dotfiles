# Doom Emacs config

This directory is symlinked to `~/.config/doom` and version controlled.

Doom's own template (`init.el`, `config.el`, `packages.el`, `custom.el`) is
generated here by `just emacs-setup` on the first machine, then committed once
and shared across platforms. Platform-specific bits belong in the
`IS-LINUX` / `IS-MAC` branches of `config.el`.
